横道图
在线表链接（推荐）下载 → DATE → 出图

粘贴 kdocs/WPS 分享链接（或 .xlsx 直接下载链接）后点「下载并生成横道图」：程序用已登录的 Edge 直接把在线表下载到程序根目录的 DATE 文件夹，再从 DATE 里读 Excel 出图。下载用的 Edge 窗口会放到另一个 Windows 虚拟桌面（按 Win+Tab 可看到），不遮挡你的桌面；首次使用请先点「打开链接（登录）」弹出可见窗口登录 kdocs（登录态会保留，之后无需重复登录）。直接粘贴 AirScript webhook 仍沿用原 webhook 拉取路径。依赖 playwright（使用系统 Edge，首次请运行 pip install playwright）。

在线拉取（webhook）—

「保存并拉取出图」= 菜单 1：先把 webhook/表名写进 gantt_config.json，再拉全量 → 出图。几万行要几十秒。
